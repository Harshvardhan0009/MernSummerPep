# Todo App

A simple and interactive Todo Application built using HTML, CSS, and Vanilla JavaScript.

## Features
- **Add Tasks**: Enter a title and description to create a new task.
- **Delete Tasks**: Remove completed or unwanted tasks from the list with a single click.
- **Input Validation**: Ensures both title and description are filled before adding a task.

## Usage
1. Open `index.html` in any web browser.
2. Fill in the task **Title** and **Description**.
3. Click **Add Todo** to insert the task into your todo list.
4. Click **Delete** on any task item to remove it.
